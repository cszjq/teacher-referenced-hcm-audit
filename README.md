# Teacher-Referenced Heatmap Coverage for Auditing Attribution Shifts in Updated CT Classifiers

This repository accompanies the following article:

**Teacher-Referenced Heatmap Coverage for Auditing Attribution Shifts in Updated CT Classifiers**  
*Journal of Imaging Informatics in Medicine*, 2026.  
DOI: https://doi.org/10.1007/s10278-026-02310-6

## Overview

This project evaluates directional, peak-aware Heatmap Coverage Metric (HCM) endpoints for auditing attribution changes between baseline and updated computed tomography classifiers under a fixed teacher-referenced protocol.

The repository is intended to provide:

- directional HCM implementations;
- deterministic analysis and evidence-building scripts;
- frozen manifests for the public cohorts;
- non-sensitive derived summary tables;
- focused tests for the reported analysis.

## Repository status

The repository is being prepared for the reproducibility release associated with the article. Public-cohort manifests, non-sensitive aggregate results, analysis code, and tests will be added in stages.

## Data availability

The public datasets used in the study are available from the repositories cited in the article.

The private EGFR cohort contains retrospective, de-identified clinical CT data and is not publicly available because of institutional and ethical restrictions. Private-cohort images and patient-level records are not included in this repository.

## Privacy

This repository does not contain:

- private clinical CT images;
- patient identifiers or patient-level private-cohort records;
- model checkpoints derived from restricted data;
- raw private-cohort attribution arrays.
